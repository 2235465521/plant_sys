# ADR 0002: 草本趣闻短视频爆款风格渲染与音画对齐架构 (Modern Trivia Video Pipeline)

- **状态**: 已接受 (Accepted)
- **日期**: 2026-10-08
- **上下文**: `plant_sys` 植物管理系统 (FastAPI 后端 + Vite/React 前端 + FFmpeg/Pillow 视频编译流水线)

## 1. 背景与问题陈述 (Context)
系统原有的古风宣纸百科风格（`style_vintage_encyclopedia`）采用泛黄古风背景、静态双线画框与学术名片排版（如门纲分类、拉丁学名）。该风格适合静态档案存档，但在抖音、微信视频号、小红书等短视频传播场景中，视觉节奏偏沉闷、文案缺乏网感故事性，难以激发用户的完播与互动。

用户提供了优质短视频标杆样本《天葵》（来自《老王聊草本》账号）。经过逐帧逆向反编译分析，该风格具有显著的爆款特征：
1. **视觉层次**：冷白天蓝通透渐变底图 + 底部柔光光斑（Soft Bokeh）；
2. **标牌设计**：顶部立体如意祥云抱字标牌，大标题字形圆润、带橙金渐变与深色描边；
3. **主体展示**：首屏采用白瓷花瓣药材盘容器抠图与自然下沉阴影，配合拼音及倾斜透视星轨环；
4. **正文排版**：高饱和亮黄色（#FFEB3B）+ 深黑描边圆润体，极具视觉冲击力；
5. **脚本结构**：4 幕轻科普叙事——封面概述、形态特征、植物趣闻（别名渊源与物候奇观）、适生范围；
6. **音画自适应**：配音解说语速与画面停留精准对齐，辅以物理惯性 3D 卷轴翻页（Page Curl）与轻柔民乐 BGM。

为了在系统中完整复刻并支持该商业级短视频风格，决定新增独立的渲染流水线与工程规范。

## 2. 决策方案 (Decisions)

### 2.1 风格预设与模型拓展 (Style Preset & Schema)
- 在系统核心枚举中新增预设标识 `style_modern_trivia`（对应前端配置“草本趣闻爆款风”）。
- 将单植物视频生成任务的默认风格切换为 `modern_trivia`，并保留原 `vintage_encyclopedia` 作为可选项。

### 2.2 4 幕趣味脚本提炼器 (Trivia Script Generator)
- 针对输入的植物信息，使用 DeepSeek API（`deepseek-v4-flash` / `deepseek-reasoner`）结构化提炼 4 幕解说词：
  - `cover_badge`: 入药部位简述（10字以内，如“干燥块根入药”）
  - `morphology`: 通俗形态特征（45~60字）
  - `trivia`: 趣味故事与生长物候奇观（45~60字）
  - `habitat`: 耐阴耐晒与地域生境（45~60字）
- 引入**离线柔性降级**：当 LLM 响应异常或超时，自动从植物数据库原生字段（`plant_aliases.origin_desc`、`habitat`、`morphology_text`）截取拼接，确保 100% 稳定出片。

### 2.3 高清透明素材与 Pillow 动态合成 (Visual Assets & Compositor)
- 建立 `backend/data/video_assets/trivia/` 独立资产包：
  - `trivia_bg.png`: 1080x1920 冷白天蓝微渐变与高斯柔光散斑；
  - `cloud_banner.png`: 对称立体如意祥云托牌底模；
  - `porcelain_dish.png`: 带边缘反光与内凹深度阴影的高光白瓷花瓣盘；
  - `orbit_ring.png`: 倾斜透视蓝色星芒粒子光轨。
- 动态排版引擎（`trivia_renderer.py`）：
  - 智能将植物入药部位图片遮罩融合至白瓷盘内部；
  - 文字渲染支持多重轮廓描边（Stroke Outline）、高光、双色渐变与拼音声调排版；
  - 正文字体采用圆润短视频爆款字体（支持幼圆 `SIMYOU.TTF` / 华文彩云等字体 fallback）。

### 2.4 语音自适应对齐与 3D 卷轴翻页 (TTS-Adaptive Sync & Compiler)
- 集成 Edge-TTS 异步语音生成器（默认 `zh-CN-YunxiNeural` 阳光科普男声），分别生成各幕音频。
- 帧分配引擎根据各幕音频的实际持续毫秒数（`duration_ms`），动态计算各 Slide 的显示停留帧数（`frames = int(duration * fps) + padding`）。
- 转场继续沿用物理 S 曲线 3D Page Curl（1.6s / 48 帧），保留真实纸张/画卡翻卷质感。
- FFmpeg 双轨混流：人声解说 100% 增益，背景音乐 20% 软音量垫底混音。

## 3. 后果与影响 (Consequences)
- **正面影响**：
  - 彻底打通单植物短视频的“平台化爆款”表现力，成片品质与主流中草药科普博主（如《老王聊草本》）完全一致。
  - 模块化解耦：旧版宣纸风格与新版趣闻风格并存互不干扰，代码可读性与可维护性高。
  - 音画精准对齐，“念完即翻”，彻底告别过去固定 5 秒切页导致的断句或过早翻页问题。
- **权衡与限制**：
  - 每次生成多调用一次 Edge-TTS 与 DeepSeek 脚本提炼，生成总体耗时相较纯静帧拼接增加约 2~4 秒（均在异步任务队列中平滑处理，对前端无阻断）。
