# ADR 0001: 语义驱动的多功能植物视频生成系统架构

- **状态**: 已接受 (Accepted)
- **日期**: 2026-08-03
- **上下文**: `plant_sys` 植物管理系统 (Vite/React 前端 + FastAPI/MySQL 后端)

## 1. 背景与问题陈述 (Context)
系统原有的视频生成引擎仅支持指定单一 `plant_id` 生成固定的 20 秒短视频。用户希望能够通过自然语言 Prompt（例如：“我想做一条关于十大中药植物介绍视频”或“帮我做一个浙八味药材视频”），自动理解意图、从数据库检索匹配的植物并一键合成符合需求的视频。

由于专题/合集视频涉及多种植物的检索、多章节剪辑、过渡幕制作以及长耗时音视频压制，直接使用同步 HTTP 请求或单一视频粗暴拼接无法满足性能与体验要求。

## 2. 决策方案 (Decisions)

### 2.1 语义意图解析 (LLM Intent Parsing)
- 使用 DeepSeek API 对自然语言 Prompt 进行语义解析，输出结构化控制指令（`Intent Schema`），包含 `mode` ("single" | "collection")、`target_count`、`style_preset` 及数据库维度筛选条件（`harvest_months`, `habitats`, `rankings`, `regions`, `keywords`）。
- 引入**柔性降级策略**：匹配过多时按语义打分截取 Top-N；匹配不足时不报错中断，按实际可用数量合成并向用户输出文字反馈。

### 2.2 异步任务队列与进度响应 (Async Task Queue)
- 采用异步任务模型处理长耗时生成。API `POST /api/video-automation/semantic-generate` 立即返回 `task_id`。
- 后台异步线程执行解析、检索、分帧渲染与音视频压制，前端通过轮询/SSE 接收百分比进度与步骤说明。

### 2.3 多植物合集视频剪辑结构 (Collection Video Stitching Pipeline)
合集视频采用模块化缝合结构：
- **主题片头 Curtain (3s)**：展示 Prompt 解析得出的专题标题（如“中国植物库专题：十大中药植物”）。
- **精简章节段落 (10~12s/植物)**：带有章节序号角标（如 `01/10 人参`），精选 3 帧精细画面。
- **章节转场动效**：植物段落之间使用 3D/卷轴翻页 (`book_flip`) 动效。
- **专题片尾 Curtain (3s)**：展示落款说明。
- **统一背景音乐**：全程铺设一条适配总时长的古风 BGM 轨道。

### 2.4 前端交互与创作工坊 (AI Video Studio Component)
- 在 `FeaturesPage` / 创作工坊加入自然语言 Prompt 输入框，配有灵感标签（`[十大中药]`、`[浙八味]` 等）。
- 提交后打开异步进度抽屉，生成完毕直接提供在线全屏播放、MP4 一键下载与历史日志查看。

## 3. 后果与影响 (Consequences)
- **正面影响**：
  - 极大提升视频创作的智能化与多功能性，支持从“单植物”到“专题合集”的全场景覆盖。
  - 异步队列设计彻底解决 Nginx/Vite 代理超时问题，前端体验平滑稳定。
  - 模块化剪辑结构保证合集视频节奏紧凑、观赏性极强。
- **权衡与限制**：
  - 多植物合集在图片缺少时需要并发抓取/处理更多图片，消耗一定 CPU/GPU 渲染资源。
